Chips

Chips are compact, interactive elements that represent an input, attribute, filter, or action. They encapsulate information into pill-shaped containers — providing a scannable and interactive way to manage selections, filters, and suggestions.

4 Types · 3 States · Icon Optional

Choice for single-select, Filter for toggling criteria, Suggestion for contextual quick actions. All chips share a fixed 32px height and border-radius: 32px. Icons (leading or trailing) are always 16×16px with a 4px gap to the label.

Usage Guidelines
🔘
Choice Chips for single selection

Use Choice Chips when a user can pick only one option from a visible set — like a size selector ("S", "M", "L"). They behave like radio buttons with a button-like visual.

🔍
Filter Chips for content filtering

Use Filter Chips to toggle active criteria. Selecting applies the filter, deselecting removes it. Multiple Filter Chips allow independent multi-axis toggling.

⚡
Suggestion Chips for contextual actions

Suggestion Chips are compact, context-aware action triggers — e.g., "Get Directions" on a map card. They carry no persistent selected state.

✂️
Keep labels short and concise

Chips are designed for 1–3 word labels. Long labels break the compact format, disrupt the visual rhythm of a group, and create uneven hit targets.

🚫
Don't use Chips for primary CTAs

Chips are not substitutes for Buttons. For a primary call-to-action, always use a Button (Filled). Chips are supplementary inputs — not the main driver of screen flow.

🔗
Chips must be contextually relevant

The information or action in a chip must be directly related to its surrounding content. Disconnected chips create cognitive noise and undermine interface trust.

Do / Don't
✓ DO
✓Short, scannable labels in a grouped row
✓Use leading icon to reinforce the selected state meaning
✓Use trailing cancel icon to let users remove an applied filter
✗ DON'T
✗Don't use long multi-word labels — Chips are designed for concise text
✗Don't use Buttons for filtering — use Filter Chips
✗Don't pre-select all chips in a Choice group — it removes meaningful selection
