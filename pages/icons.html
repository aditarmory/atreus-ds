Iconography

Atreus iconography uses a 24px canvas and references the hibank Figma source directly. This page now renders from reusable SVG assets and a generated manifest so Foundation consumers can preview, inspect, and copy the current icon set from a single source of truth.

24px Canvas · Multi-style System

Most Atreus icons live in neutral black on a 24 × 24px bounding box. The generated asset set keeps the existing Foundation presentation, while surfacing which icon groups are already exported locally and which still exist only in the upstream Figma library.

Specifications
24
Base Size

Every exported icon asset is normalized for Foundation usage on a 24px canvas so the previews, copied SVG, and downstream implementation all align to the same sizing rule.

Aa
Naming

Asset filenames use the Figma labels converted to kebab-case, such as icon-transfer.svg and icon-customer-service.svg, while the cards keep the original display names.

#
Color

Primary icon fill maps visually to neutral text color #1A1A1A. Accent or semantic color should be applied by component context, not by redefining the exported glyph.

UI
Asset Status

Cards with a live preview are backed by a local SVG file and support direct SVG copy. Cards without a preview remain documented so the Foundation inventory still reflects the full Figma source.
