Iconography

Atreus iconography uses a 24px canvas and references the hibank Figma source directly. This page documents the current inventory, dominant styles, and naming taxonomy used across the design system.

104 icon groups · 226 variants Inventory is synced from the Figma node provided for Atreus DS iconography.

24px Canvas · Multi-style System

Most Atreus icons live in neutral black on a 24 × 24px bounding box. Figma currently leans on Outlined, Filled, and Round treatments, with a smaller set of contextual variants for utility actions and product-specific flows.

Base Size

All representative source icons in this page use the 24px grid from Figma. That keeps alignment predictable when icons sit beside labels, chips, controls, and list items.

Naming

Group names and counts follow the exact labels found in the Iconography frame, including product-specific entries like BI Fast, Mobile-Pembelian, and Customer service.

#
Color

Primary icon fill maps visually to neutral text color #1A1A1A. Accent or semantic color should be applied only by component context, not by redefining the source glyph.

UI
Usage

Use the source variant that already exists in Figma instead of mixing styles ad hoc. For example, prefer documented round, filled, or outlined states rather than inventing a new treatment.
