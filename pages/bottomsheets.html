Usage Guidelines
🎯
Use for contextual actions only

Bottom sheets are best for confirmations, choices, or supplementary info directly tied to the current page content. They are not a replacement for primary navigation or full-screen pages.

⚡
Blocker for error states

Use Blocker Bottom Sheet for flows that need to interrupt the user: account not found, insufficient balance, lost connection, or login required. Each has a pre-defined layout — don't modify it arbitrarily.

🔢
Choose the right Group variant

Transactional = two equal choices (side-by-side). Destructive = one primary action + cancel (stacked). Acknowledgement = single CTA only, no alternative path exists.

✍️
Keep content to 1–2 sentences

The description area is intentionally constrained. If the content requires more explanation, it belongs on a separate page or full-screen modal — not inside a bottom sheet.

Do / Don't
