List Item

List Items are the fundamental building block of any list-based layout in hibank. They present structured content — text, metadata, and actions — in a consistent, touch-friendly row. Each item supports a leading element (icon, avatar, or thumbnail), a label + supporting text, and a trailing element (value, action, or control).

Usage Guidelines
📋
Use the right size for context

Small for dense lists (settings, menus), Medium for standard content (accounts, transactions), Large for rich content with thumbnails or long descriptions.

🏷️
Match badge variant to status severity

Always use Success/Warning/Error/Info badges consistently to match the Snackbar semantic color system — users build pattern recognition across the product.

💰
Use negative color for debit amounts

Value text showing deductions or debits should use $semantic-error (#CE0101). Credits and balances use $text-primary (#1A1A1A).

📱
Always use dividers between items

Use 1px #F3F3F3 dividers between list items — never rely on spacing alone for list separation. The bottom item in a group omits its divider.

🔀
Keep trailing elements consistent within a list

Within a single list group, all items should share the same trailing type — all chevrons, all badges, or all values. Mixing trailing types creates visual noise.

🔢
Limit label to 1 line, support to 2 lines

Labels should never wrap. Supporting text may wrap to 2 lines max in Large size — if more is needed, reconsider the information architecture.
